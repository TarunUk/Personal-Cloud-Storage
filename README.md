🚀 Serverless Personal Cloud Storage System

A cloud-based file storage application built using AWS serverless architecture. It allows users to securely upload and manage files without handling traditional servers.

⚙️ Tech Stack

AWS Lambda, API Gateway, Amazon S3, AWS Amplify, Amazon Cognito, Python, Docker, GitHub Actions

✨ Features

Serverless backend architecture

Secure file upload & storage

Scalable cloud infrastructure

CI/CD automation with GitHub Actions

Docker support

🔄 Workflow

User → Frontend → API Gateway → Lambda → S3
